Dollar-Value LIFO

Problem

On January 1, 20X1, Starlight Supply Company adopted the dollar-value LIFO method. The inventory value for its one inventory pool on this date was $300,000. Inventory data for 20X1 through 20X5 are as follows:

Note: Change = base-year dollars this year − base-year dollars the year before.

Note: 20X4 is a decrease, so its cost index of 1.15 is never used. A decrease takes base-year dollars out of earlier layers, at the index of the year each layer was added.

Required: calculate Starlight’s ending inventory for 20X1, 20X2, 20X3, 20X4 and 20X5.

Ending inventory, 12/31/20X1
EI = 300,000 + 30,000 × 1.04 = $331,200
Ending inventory, 12/31/20X2
EI = 300,000 + 30,000 × 1.04 + 25,000 × 1.08 = $358,200
Ending inventory, 12/31/20X3
EI = 300,000 + 30,000 × 1.04 + 25,000 × 1.08 + 15,000 × 1.10 = $374,700
Ending inventory, 12/31/20X4
EI = 300,000 + 30,000 × 1.04 + (25,000 − 10,000) × 1.08 + (15,000 − 15,000) × 1.10 = $347,400
Note: The decrease of 25,000 comes out of the newest layers first: 15,000 from the 20X3 layer, which leaves 0, then 10,000 from the 20X2 layer. 15,000 + 10,000 = 25,000. No layer is added for 20X4.
Ending inventory, 12/31/20X5
EI = 300,000 + 30,000 × 1.04 + (25,000 − 10,000) × 1.08 + (15,000 − 15,000) × 1.10 + 15,000 × 1.20 = $365,400
